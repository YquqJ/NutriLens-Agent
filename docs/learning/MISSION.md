# Mission: Agent 应用开发求职

## Why
用户有 8 年前端开发经验，希望以 NutriLens 为主项目，尽快补齐 Python、LLM、LangGraph、RAG、可靠性与 AI 前端交互能力，成功求职 Agent/AI 应用开发岗位。

## Success looks like
- 能在 3 分钟内讲清 NutriLens 的端到端架构与关键取舍。
- 能独立读写一个带工具调用、状态和中断恢复的 Agent 流程。
- 能解释并调试路由错误、死循环、上下文污染、RAG 失效和 SSE 断流。
- 能用项目代码和测试证据回答常见 Agent 面试问题。

## Constraints
- 当前 Agent/后端知识接近入门水平；前端工程经验较强。
- 以项目导读和小练习为主，优先掌握求职高频内容，避免泛学底层模型训练。

## Out of scope
- 暂不深入模型训练、Transformer 数学推导、Kubernetes 和复杂分布式平台。
