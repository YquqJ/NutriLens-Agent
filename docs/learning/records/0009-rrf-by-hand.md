# RRF 手算与代码阅读层级

用户已能理解向量检索距离越小越相关，以及扩大候选池可减少漏召回。需要继续巩固 RRF 具体计算与故障降级。

纠正点：

- embedding 失败意味着无法生成 query 向量，因此不能回退到向量检索；应退化为 `keyword_search` 的 BM25 结果。
- RRF 是多榜单排名融合：每条路按 `1 / (60 + rank)` 贡献分数，两条路都靠前的同一切片累计更高。
- RRF 的作用不是理解语义，而是避免直接比较余弦距离和 BM25 原始分数。

教学策略更新：用户当前优先掌握链路和关键决策代码；不要求逐行理解 SQLAlchemy、pgvector 或 Python 容器的所有语法。先读“控制流和数据边界”，辅助语法按需补。
