Supervisor：模型提出建议，程序执行并约束建议

对应代码：backend/app/agents/supervisor.py。目标：解释一次路由为什么既需要 LLM，又不能只信任 LLM。

流程

AgentState
  → 先检查 hop_count
  → 组装 system prompt + summary + 图片事实 + messages
  → LLM 输出 RouteDecision
  → 程序拦截重复路由
  → Command(goto, update)

核心对象

class RouteDecision(BaseModel):
    next_agent: RouteTarget
    task: str

结构化输出不是为了“让模型更聪明”，而是把不确定的自然语言压缩进可验证的数据契约。

四层保护

  1. 合法路由目标：不能跳到不存在的节点。
  2. 真实日期：避免模型凭记忆解释“今天/昨天”。
  3. MAX_HOPS：直接中止循环。
  4. 相同 worker 连续路由：强制结束，避免重复回答。
面试表达：我用 LLM 处理意图识别和跨轮指代，用程序处理状态更新、合法跳转和循环边界。
